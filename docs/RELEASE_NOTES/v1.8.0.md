# AfuDM v1.8.0 — Automation

AfuDM now includes an automation queue for download follow-up work. It provides
clear progress, cancellation, and retry controls, while the main-branch integration
conflicts have been resolved for a stable release baseline.

## Highlights

- Automation queue for post-download actions.
- Queue items expose progress, cancellation, and retry controls in the UI.
- Main merge conflicts were resolved before release.

## Added

- Automation queue persistence and API support.
- Localized UI strings and controls for automation state.

## Changed

- Download management can schedule and track follow-up steps.

## Fixed

- Resolved integration conflicts in the main branch.

## Security

- No security-specific changes in this release.

## Known Issues

- No known release-blocking issues.

## Install

Download the Windows zip, verify its SHA-256 checksum, extract it, and run `AfuDM.exe`.
