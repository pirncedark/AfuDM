# AfuDM v1.7.5 — Mobile &amp; Settings

AfuDM's settings are no longer hidden in config files. Seven previously internal
options are now first-class UI controls in a tabbed, searchable Settings panel, and the
phone interface became an installable PWA you can pair with a QR code. This release also
closes two extension security holes and fixes Turkish-aware search in the main list.

## Highlights

- Tabbed, searchable Settings panel — find any option by typing.
- Seven hidden options surfaced: remote access, network, clipboard, speed, tracker health and more.
- Phone UI is now an installable PWA (manifest + service worker, offline shell).
- QR pairing: scan once to connect your phone to the desktop instance.

## Added

- `ui/mobil.html`, `ui/manifest.webmanifest`, `ui/sw.js` — installable phone interface.
- QR pairing flow for desktop/phone handshake.
- Settings contract documented in `docs/v175_SOZLESME.md`.
- Tests: `tests/v175_ayar_test.py`, `tests/v175_mobil_test.py`, `tests/pwa_test.py`,
  `tests/tr_arama_test.py`, expanded `tests/maestro_test.mjs`.

## Changed

- Settings rebuilt as tabs with live search instead of one long list.
- Main list search uses tr-TR I/i case folding, so "İ/ı" and "I/i" match as a Turkish user expects.

## Fixed

- Maestro header leak: request headers could cross into unrelated pages.
- `postMessage` channel isolation closed — the extension now validates the channel origin.

## Security

- Extension header policy enforced through `extension/header-policy.js`.
- Maestro content script communicates over a dedicated, isolated channel.

## Known Issues

- PWA install prompt requires HTTPS or localhost; plain-HTTP LAN access installs as a shortcut only.

## Install

Download the zip below, extract it, and run `AfuDM.exe`. Verify the SHA-256 first.

## Turkce

Ayarlar artik yapilandirma dosyasinda saklanmiyor. Daha once gizli olan yedi secenek
sekmeli ve aranabilir Ayarlar panelinde gercek birer kontrol oldu; telefon arayuzu
kurulabilir bir PWA'ya donustu ve QR ile eslestiriliyor. Ayrica eklentideki iki guvenlik
acigi kapatildi ve ana liste aramasi Turkce I/i kuralina gecti.

### One cikanlar
- Sekmeli, aranabilir Ayarlar paneli.
- Gizli 7 ayar arayuze acildi: uzaktan erisim, ag, pano, hiz, tracker durumu ve digerleri.
- Telefon arayuzu kurulabilir PWA (manifest + service worker, cevrimdisi kabuk).
- QR eslestirme: telefonu masaustu ornegine tek okutmayla bagla.

### Eklendi
- `ui/mobil.html`, `ui/manifest.webmanifest`, `ui/sw.js` telefon arayuzu.
- QR eslestirme akisi.
- `docs/v175_SOZLESME.md` ayar sozlesmesi.
- Testler: v175_ayar, v175_mobil, pwa, tr_arama + genisletilmis maestro testi.

### Degisti
- Ayarlar tek uzun liste yerine sekme + canli arama.
- Ana liste aramasi tr-TR I/i buyuk-kucuk kuralina gecti.

### Duzeltildi
- Maestro baslik sizintisi: istek basliklari ilgisiz sayfalara gecebiliyordu.
- `postMessage` kanal izolasyonu kapatildi; eklenti kanal kaynagini dogruluyor.

### Guvenlik
- Eklenti baslik politikasi `extension/header-policy.js` ile zorunlu kilindi.
- Maestro icerik betigi ozel, izole bir kanal kullaniyor.

### Bilinen sorunlar
- PWA kurulum istemi HTTPS veya localhost ister; duz HTTP yerel ag erisiminde yalnizca kisayol olarak kurulur.

### Kurulum
Asagidaki zip'i indir, cikar ve `AfuDM.exe` calistir. Once SHA-256 dogrula.
