# AfuDM v2.7.1 — Maintenance & Recovery

This patch release recovers work left in old local copies that forked before v2.7.0, hardens deletion and the mobile download bridge, and cleans up the repository.

## Highlights
- **Safe deletion restore:** orphaned tasks from pre-v2.7.0 local copies are recovered; `_delete_targets` was rewritten to use `rmtree` for folders, force `S_IWRITE` on read-only files and clear `.part`/`.ytdl`/`.temp`/`.aria2` leftovers (retry on Windows file locks preserved). The remove target list now also includes `title`, `options` and `.torrent`.
- **New `/dosya` API endpoint:** never trusts a client-supplied path — it resolves the server path by `gid` and verifies it stays inside the download root (`is_relative_to`). `/indir` stays for backward compatibility.
- **Mobile "download to phone":** a `__telefon` layer lets a finished download be pulled to the phone via `/dosya` (`data-eylem="telefon"`).
- **UI polish:** hover states, grid layout, brand gradient and responsive breakpoints improved.
- **Repository cleanup:** packaged zip, patch files and previous release notes no longer live in the repository.

## Added
- `api/server.py`: new `/dosya` endpoint with `gid`-based path resolution and download-root containment check (`is_relative_to`).
- `ui/mobil.html`: `__telefon` layer so finished desktop downloads can be transferred to the phone.

## Fixed
- `core/manager.py`: `_delete_targets` rewritten for safe recursive deletion (folders via `rmtree`, read-only via `S_IWRITE`, temp files `.part`/`.ytdl`/`.temp`/`.aria2` cleaned; Windows lock retry kept). Remove targets now include `title`, `options`, `.torrent`.
- `app.py` + `core/servis.py`: `remove`'s `delete_files` is normalized to `bool` even when sent as a dict, keeping desktop and web UI consistent.
- `ui/app.js`: engine retry now calls `reliability_restart_engine`; `remove` is sent as a boolean.
- Android: missing `MediaInfo` import added in `HomeScreen.kt` (`b1421f3`).
- UI: CSS polish — hover states, grid layout, brand gradient, responsive breakpoints (`d7d73f9`).
- CI: correct APK artifact path and updated `setup-java` to v5 (`fdc8c98`).
- `extension/manifest.json` version was stuck at `2.6.0`; now in sync with `core/surum.py` at `2.7.1`.
- Repository hygiene: `AfuDM-v2.7-win64.zip`, `diff.patch`, `diff.txt`, `release_notes.txt` removed from the repository (kept on disk); `.gitignore` extended accordingly.

## Changed
- `SURUM` updated to `2.7.1` in `core/surum.py` and `extension/manifest.json`.
- CI dependencies bumped: `actions/setup-java` 5→6 (#19), `gitleaks/gitleaks-action` 2→3 (#18), `github/codeql-action` 3→4 (#17).
- Added tests for `delete_targets` and a 134-line `telefona_indir_test.py` covering the mobile transfer path.

Kaldırma hedefine `title`, `options` ve `.torrent` da eklendi.
- **Yeni `/dosya` ucu:** istemciden yol almaz — `gid` ile sunucu yolunu bulur ve indirme kökünün içinde olduğunu (`is_relative_to`) doğrular. Geriye uyumluluk için `/indir` yerinde bırakıldı.
- **"Telefona indir":** `__telefon` katmanı sayesinde biten indirme `/dosya` ucuyla telefona çekilebilir (`data-eylem="telefon"`).
- **UI cilası:** hover durumları, grid düzeni, marka gradyanı ve responsive kırılımlar iyileştirildi.
- **Depo temizliği:** paketlenmiş zip, yama dosyaları ve eski sürüm notları artık depoda tutulmuyor.
