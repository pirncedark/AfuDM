# AfuDM v2.7.2 — Sharing & Reliability

This patch release makes "Share on Network" work end to end — including from a different network through a Cloudflare Quick Tunnel — fixes wrong file names and sizes after yt-dlp merges, and hardens the local API, share cleanup and database restore. The release EXE is now always built from the current sources.

## Highlights
- **Share from anywhere:** "Share on Network" returns a LAN link and, when available, an internet link through a Cloudflare Quick Tunnel (pinned `cloudflared` 2026.9.1, SHA-256 verified). The QR code uses the internet link. Opening either link on a phone now **downloads** the file instead of playing it in the browser.
- **Correct video file name and size:** after yt-dlp merges video and audio, the record points to the merged `.mp4`/`.mkv`/`.webm` (not the `.fNNN.m4a` fragment) and shows the real size. Older broken records are repaired automatically.
- **Share cleanup:** SMB shares (`Everyone,READ`) and their staging copies are removed on delete, on exit and — after a crash or forced close — on the next startup.
- **Safer local API:** paths are confined to the download root, query tokens and wildcard CORS are restricted, and stream/cleanup errors are reported instead of swallowed.
- **Tidier download row:** badge and actions stay on one line at every width; secondary actions collapse to icons with tooltips.

## Added
- Cloudflare Quick Tunnel for "Share on Network" with an isolated loopback server that only serves `GET/HEAD /s/<token>`; new "Internet sharing" setting (on by default) (#25).
- Window opens at a size that fits all content, DPI-aware (#25).
- Startup cleanup of leftover `AfuDM_*` SMB shares and staging copies (#48).
- Headless end-to-end suite with the real backend (`tests/e2e/`, 11 scenarios) (#43); headless panel/veil interaction and bridge-mapping tests (#30).

## Fixed
- Wrong file name after yt-dlp merge ("file not found" on Share/Open) and stale `.fNNN` records (#35).
- Real file size reported after yt-dlp post-processing (#41).
- Internet share link sent `video/mp4` without `Content-Disposition`; phones played the video instead of downloading it (#49).
- `net.exe` output is read with the OEM code page; Turkish Windows raised `UnicodeDecodeError` and "not found" could not be detected (#48).
- Download row: "Delete" no longer wraps; share/scan colors were never applied (dead CSS selectors); meaningless "–" hidden for finished items; status column no longer collapses at 700–850 px (#48).
- Drawer and Share Center close with Escape/backdrop; bridge errors are shown instead of swallowed (#42).
- Database restore keeps the shared store stable; `events.gid` migration is idempotent (#40).
- Deletion tests repaired and added to CI (#29).
- `video/` package included in the release bundle (#36).

## Security
- Local API: destinations and `/indir` confined to the download root (403 outside), query-token only for mobile `/dosya`, CORS limited to extension and loopback origins (#37).
- LAN pairing token delivered only to loopback clients; share list rendered safely (XSS) (#44).
- Cookie and Authorization headers removed from aria2 session files (#40).
- SMB shares no longer stay open after delete, exit or crash (#44, #48).

## Changed
- Release EXE is built with PyInstaller from current sources in CI and release; stale or missing executables fail the build (#26).
- `SURUM` is `2.7.2` in `core/surum.py` and `extension/manifest.json`.

## Known Issues
- The internet link needs the `cloudflared` engine; if it is missing, AfuDM asks before downloading it and falls back to the LAN link.
- Closing the window hides AfuDM to the tray; use the tray "Exit" to quit fully.

## Install
1. Download `AfuDM-v2.7.2-win64.zip` and verify it against the SHA-256 below.
2. Extract anywhere and run `AfuDM.exe` (portable, no installer).

Yayın EXE'si artık her zaman güncel kaynaktan derlenir.

## Öne Çıkanlar
- **Her yerden paylaşım:** "Ağda Paylaş" LAN linki ve varsa Cloudflare Quick Tunnel üzerinden internet linki verir (sabitlenmiş `cloudflared` 2026.9.1, SHA-256 doğrulamalı). QR internet linkini kullanır. İki link de telefonda artık tarayıcıda oynatmak yerine dosyayı **indirir**.
- **Doğru video adı ve boyutu:** yt-dlp birleştirmesinden sonra kayıt ara parçayı (`.fNNN.m4a`) değil birleşik `.mp4`/`.mkv`/`.webm` dosyasını ve gerçek boyutu gösterir. Eski bozuk kayıtlar otomatik onarılır.
- **Paylaşım temizliği:** SMB paylaşımları (`Everyone,READ`) ve kopyaları silmede, çıkışta ve çökme/zorla kapatma sonrası açılışta kaldırılır.
- **Daha güvenli yerel API:** yollar indirme köküyle sınırlı, query token ve joker CORS daraltıldı, akış/temizlik hataları artık yutulmuyor.
- **Derli toplu indirme satırı:** rozet ve düğmeler her genişlikte tek satırda; ikincil düğmeler ipuçlu ikona döner.

## Eklenenler
- Ağda Paylaş için Cloudflare Quick Tunnel; yalnız `GET/HEAD /s/<token>` sunan yalıtılmış loopback sunucusu; "İnternet paylaşımı" ayarı (varsayılan açık) (#25).
- Pencere tüm içeriği sığdıran boyutta, DPI uyumlu açılır (#25).
- Açılışta artık `AfuDM_*` SMB paylaşımları ve kopyaları temizlenir (#48).
- Gerçek arka uçlu headless uçtan uca test seti (`tests/e2e/`, 11 senaryo) (#43); headless panel ve köprü eşleme testleri (#30).

## Düzeltilenler
- yt-dlp birleştirmesi sonrası yanlış dosya adı ("dosya bulunamadı") ve eski `.fNNN` kayıtları (#35).
- Son işlemden sonra gerçek dosya boyutu (#41).
- İnternet paylaşım linki `video/mp4` ve `Content-Disposition`'sız gidiyordu; telefon indirmek yerine oynatıyordu (#49).
- `net.exe` çıktısı OEM kod sayfasıyla okunur; Türkçe Windows'ta `UnicodeDecodeError` oluşuyordu (#48).
- İndirme satırı: "Sil" alta kaymıyor; paylaş/tara renkleri (ölü CSS seçicileri) uygulanıyor; biten işte "–" gizlendi; 700–850 px'te durum sütunu çökmüyor (#48).
- Çekmece ve Paylaşım Merkezi Esc/arka planla kapanır; köprü hataları gösterilir (#42).
- Veritabanı geri yüklemede ortak store korunur; `events.gid` migration'ı idempotent (#40).
- Silme testleri onarıldı ve CI'a bağlandı (#29).
- `video/` paketi yayın paketine eklendi (#36).

## Güvenlik
- Yerel API: hedefler ve `/indir` indirme köküyle sınırlı (dışı 403), query token yalnız mobil `/dosya`, CORS uzantı ve loopback ile sınırlı (#37).
- LAN eşleme jetonu yalnız loopback istemcilere; paylaşım listesi güvenli render (XSS) (#44).
- aria2 oturum dosyalarından Cookie/Authorization başlıkları kaldırıldı (#40).
- SMB paylaşımları silme, çıkış veya çökme sonrası açık kalmaz (#44, #48).

## Değişenler

- `SURUM`, `core/surum.py` ve `extension/manifest.json` içinde `2.7.2`.

- İnternet linki `cloudflared` motoru ister; yoksa indirmeden önce sorulur, LAN linki çalışmaya devam eder.
- Pencereyi kapatmak AfuDM'i tepsiye gizler; tamamen çıkmak için tepsideki "Çıkış".
