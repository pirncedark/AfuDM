# AfuDM v2.9.6 — Cross-site Download Links Fix

This release stops the browser extension from taking over links that the browser itself would only open as pages.

## Highlights

- Links with a `download` attribute that point to another website are no longer sent to AfuDM; the page opens normally (for example a quality-picker page).
- Same-site download links and real file downloads still go to AfuDM.

## Fixed

- Browsers honor the `download` attribute only for same-site links; for other sites the link just navigates. The extension used to take such clicks over and sent the landing page to AfuDM as a file. It now follows the browser's rule. Verified in a real headless Chromium with a fake AfuDM API.

## Install

Download `AfuDM-v2.9.6-win64.zip`, extract it and run `AfuDM.exe`. Reload the Chrome extension after updating. Existing installs update automatically.

## Türkçe

Bu sürüm, tarayıcının yalnızca sayfa olarak açacağı linklerin uzantı tarafından AfuDM'e devralınmasını durdurur.

## Öne çıkanlar

- Başka bir siteye giden ve `download` niteliği olan linkler artık AfuDM'e gönderilmez; sayfa normal açılır (örneğin kalite seçme sayfası).
- Aynı siteden indirme linkleri ve gerçek dosya indirmeleri yine AfuDM'e gider.

## Düzeltilenler

- Tarayıcılar `download` niteliğini yalnız aynı siteye giden linklerde uygular; başka sitelerde link sadece sayfayı açar. Uzantı bu tıklamaları devralıp açılış sayfasını AfuDM'e dosya diye gönderiyordu. Artık tarayıcının kuralına uyuyor. Gerçek headless Chromium ve sahte AfuDM API'siyle doğrulandı.
