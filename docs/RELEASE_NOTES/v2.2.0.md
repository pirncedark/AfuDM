# AfuDM v2.2.0 — Windows Integration

AfuDM v2.2.0 makes AfuDM behave like a native Windows download manager. It can register an Explorer right-click entry, handle `afudm://` links, associate `.afup`, `.torrent` and magnet files, start with Windows, show Windows notifications and trigger a Defender scan. Every integration is opt-in, applied only for the current user, and can be removed from the interface.

## Highlights

- Explorer right-click entry: "Download with AfuDM".
- `afudm://` protocol handler, so a browser can hand links straight to the app.
- File associations for `.afup`, `.torrent` and magnet links.
- Start with Windows (tray mode) and native Windows notifications.
- Defender scan for completed downloads.
- One panel showing the live registry state of every integration, with apply, test and remove.

## Added

- `core/windows_integration.py`: registry writes scoped to the current user, with the previous value backed up before any change.
- Windows integration panel in Settings, listing all seven integrations with their current state.

## Changed

- Window controls no longer depend on the download engine (see Fixed).

## Fixed

- **The window could not be moved or closed.** When the engine failed to connect, the custom title bar class was never applied, so neither the window buttons nor the drag region were ever created — and because the native title bar is folded into the client area, the window was left with no handle at all. The title bar is now set up independently of engine state, and the controls are wired defensively so a missing element cannot break the rest of the UI.
- **The interface locked up silently while the engine was connecting.** It now reports a failure after 15 seconds and offers Retry instead of waiting forever.
- **`AttributeError: 'Manager' object has no attribute 'windows'`** — the API object read the attribute unconditionally, breaking any consumer with a lighter Manager.

## Security

- Registry changes are written under the current user only, never machine-wide, and the previous value is backed up so Remove restores it.

## Known Issues

- A Windows service host is not packaged in this build; background service mode reports as unavailable.

## Install

Download the Windows zip, extract it, and run `AfuDM.exe`.

## Türkçe

AfuDM v2.2.0 uygulamayı yerli bir Windows indirme yöneticisi gibi davranır hale getirir. Explorer sağ tık girdisi kaydedebilir, `afudm://` bağlantılarını karşılar, `.afup`, `.torrent` ve magnet dosyalarını ilişkilendirir, Windows ile başlar, Windows bildirimi gösterir ve Defender taraması tetikler. Her entegrasyon isteğe bağlıdır, yalnızca geçerli kullanıcı için uygulanır ve arayüzden kaldırılabilir.

### Öne çıkanlar

- Explorer sağ tık girdisi: "AfuDM ile indir".
- `afudm://` protokol işleyicisi; tarayıcı bağlantıyı doğrudan uygulamaya verebilir.
- `.afup`, `.torrent` ve magnet bağlantıları için dosya ilişkilendirmesi.
- Windows ile başlat (tepsi kipi) ve yerli Windows bildirimleri.
- Biten indirmeler için Defender taraması.
- Her entegrasyonun canlı kayıt durumunu gösteren tek panel; uygula, test et, kaldır.

### Eklendi

- `core/windows_integration.py`: yalnızca geçerli kullanıcı kapsamında kayıt defteri yazımı; her değişiklikten önce önceki değer yedeklenir.
- Ayarlar içinde yedi entegrasyonu ve durumlarını listeleyen Windows entegrasyon paneli.

### Değişti

- Pencere kontrolleri artık indirme motoruna bağlı değil (bkz. Düzeltildi).

### Düzeltildi

- **Pencere hareket ettirilemiyor ve kapatılamıyordu.** Motor bağlanamayınca özel başlık çubuğu sınıfı hiç uygulanmıyor, dolayısıyla ne pencere düğmeleri ne de sürükleme alanı oluşuyordu; Windows başlığı istemci alanına katıldığı için pencere tamamen tutamaksız kalıyordu. Başlık çubuğu artık motor durumundan bağımsız kuruluyor, kontroller de eksik öğe arayüzün geri kalanını kıramayacak şekilde bağlanıyor.
- **Motor bağlanırken arayüz sessizce kilitleniyordu.** Artık 15 saniye sonra hata bildirip "Yeniden dene" sunuyor, sonsuza kadar beklemiyor.
- **`AttributeError: 'Manager' object has no attribute 'windows'`** — API nesnesi alanı koşulsuz okuyor, daha hafif Manager veren her tüketiciyi kırıyordu.

### Güvenlik

- Kayıt defteri değişiklikleri yalnızca geçerli kullanıcı altına yazılır, makine geneline asla; önceki değer yedeklendiği için Kaldır onu geri getirir.

### Bilinen sorunlar

- Bu pakette Windows servis barındırıcısı yoktur; arka plan servis kipi kullanılamaz olarak bildirilir.

### Kurulum

Windows zip dosyasını indir, arşivi çıkar ve `AfuDM.exe` dosyasını çalıştır.
