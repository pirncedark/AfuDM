# AfuDM v2.4.0 — Mobile Companion

AfuDM now officially supports a full-featured Mobile Companion Web UI. You can access the remote control panel from your phone, seamlessly manage your downloads, and even download completed files directly to your mobile device. The Settings menu has also been polished with a new Basic/Advanced toggle.

## Highlights
- **Mobile Companion:** Access the PC download manager from your phone's browser over the local network via `http://<ip>:8010/m`.
- **Download to Phone:** A new endpoint allows you to download completed files from your PC directly into your phone's storage.
- **PWA Installation:** The mobile UI provides a seamless PWA installation prompt to install AfuDM on your phone's home screen, functioning like a native APK.
- **UI/UX Polish:** The Settings menu now separates Basic and Advanced configurations for a cleaner experience, and the desktop UI features a global version indicator.

## Added
- New `/indir` secure API endpoint to stream completed downloads.
- `Telefona İndir` button in the mobile UI for completed tasks.
- `Uygulamayı Kur (APK/PWA)` persistent button in the mobile header with fallback installation instructions for HTTP network connections.
- Advanced settings toggle in the Desktop UI to hide complex power-user features by default.
- Global version indicator placed statically in the bottom right corner.

## Changed
- The sidebar scrollbar on the desktop UI is visually hidden while preserving scroll functionality.
- The mobile UI folder selector now explicitly displays the default download directory path when categories are disabled.
- The `i18n` dictionary format properly enforces structural checks during the CI test suite.

## Türkçe

AfuDM artık tam özellikli bir Mobil Uzaktan Kumanda (Mobile Companion) arayüzünü destekliyor. Telefonunuzun tarayıcısından bilgisayarınızdaki AfuDM'i yönetebilir, biten dosyaları doğrudan telefonunuzun hafızasına indirebilirsiniz. Ayarlar menüsü de yeni bir Temel/Gelişmiş ayrımıyla çok daha sadeleştirildi.

## Öne Çıkanlar
- **Mobil Kumanda:** Masaüstündeki indirme yöneticisine yerel ağ üzerinden `http://<ip>:8010/m` adresiyle telefonunuzdan bağlanın.
- **Telefona İndir:** Biten dosyaları PC'nizden doğrudan telefonunuza indirebilmeniz için yeni bir API uç noktası eklendi.
- **PWA Kurulumu:** Mobil arayüz, AfuDM'i telefonunuzun ana ekranına bir APK kuruyormuş gibi kolayca eklemeniz için kurulum yönlendirmesi içerir.
- **UI/UX İyileştirmesi:** Ayarlar penceresinde artık Gelişmiş Ayarlar tek bir tuşla gizlenip açılabiliyor. Masaüstü uygulamasının sağ alt köşesinde ise kalıcı bir sürüm numarası eklendi.

## Eklenenler
- Biten indirmeleri aktarmak için güvenli `/indir` uç noktası.
- Mobil arayüzde tamamlanan işler için `Telefona İndir` butonu.
- Mobil arayüzün üst kısmında, yerel ağ HTTP kısıtlamalarına karşı çözüm sunan `Uygulamayı Kur (APK/PWA)` butonu.
- Masaüstü arayüzünde güç kullanıcılarına (power-user) hitap eden ayarları varsayılan olarak gizleyen Gelişmiş Ayarlar düğmesi.
- Masaüstü ekranında, sağ alt köşeye sabitlenmiş sürüm göstergesi.

## Değişenler
- Masaüstü sol menüsündeki çirkin kaydırma çubuğu (scrollbar), kaydırma özelliği bozulmadan görsel olarak gizlendi.
- Mobil arayüzdeki "Hedef Klasör" seçim kutusu, kategori özelliği kapalı olsa bile artık bilgisayardaki varsayılan indirme dizinini net olarak gösteriyor.
- `i18n` sözlük formatı CI testlerinde daha sıkı denetlenerek eksik anahtarların önüne geçildi.
