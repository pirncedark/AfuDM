# AfuDM v2.9.0 — Clean Browser Handoff

Browser downloads handed to AfuDM now open only a small download window instead of bringing up the main panel. Chrome and AfuDM no longer download the same file at the same time, and a browser download is never lost if the handoff fails. PDF links without a file extension are saved with the correct name.

## Highlights
- A dedicated download window replaces the main panel when a download comes from the browser.
- One download, one prompt: Chrome keeps the file unless AfuDM accepts it.
- Correct names for PDFs served from extensionless links.

## Added
- Small download window for browser handoffs, in Turkish and English, with the same category folders, video quality and audio-only options as the main panel.
- Pending browser downloads are saved and shown again after AfuDM restarts.
- Handoff and approval errors are written to the event log.
- AfuTube: open the folder of a finished download and share it (#84).

## Changed
- The browser extension pauses the Chrome download first and cancels it only after AfuDM confirms the handoff; on failure, timeout or when AfuDM is closed, Chrome resumes.
- Repeated browser events for the same download create a single AfuDM download.
- Browser requests are asked only in the download window, never twice.

## Fixed
- The main panel no longer comes to the front during a browser download.
- Chrome and AfuDM could both download the same file.
- Extensionless PDF links (for example `Content-Disposition: inline`) were saved without `.pdf`; the server file name is now used.
- Closing the download window with X no longer drops the request; only "Cancel" discards it.
- Closing AfuDM or applying an update fully exits the app.
- Extension message says "pick the folder" instead of "queued" while AfuDM waits (#88).
- Never return a null error message; pausing finished downloads is tolerated (#87).
- AfuTube: portrait video quality, daily update check and bug report fixes (#86, #89).

## Security
- Cookies, headers and user agent of pending browser downloads stay in memory only and are not written to disk.

## Known Issues
- After a restart, a pending download that needs a browser login may have to be sent again from the browser.

## Install
1. Download `AfuDM-v2.9.0-win64.zip` and verify it against the SHA-256 below.
2. Extract it anywhere and run `AfuDM.exe` (portable, no installer).
3. Reload the AfuDM browser extension so the new handoff takes effect.

## Türkçe

Tarayıcıdan AfuDM'ye gelen indirmeler artık ana paneli öne getirmiyor; yalnız küçük bir indirme penceresi açılıyor. Chrome ve AfuDM aynı dosyayı aynı anda indirmiyor; devir başarısız olursa tarayıcı indirmesi kaybolmuyor. Uzantısız PDF bağlantıları doğru adla kaydediliyor.

## Öne Çıkanlar
- Tarayıcı indirmesinde ana panel yerine ayrı indirme penceresi.
- Tek indirme, tek onay: AfuDM kabul etmedikçe dosya Chrome'da kalır.
- Uzantısız bağlantılardan gelen PDF'ler doğru adla kaydedilir.

## Eklenenler
- Tarayıcı devri için küçük indirme penceresi (Türkçe/İngilizce); kategori klasörleri, video kalitesi ve yalnız ses seçenekleri ana paneldekiyle aynı.
- Bekleyen tarayıcı indirmeleri saklanır, AfuDM yeniden açılınca tekrar sorulur.
- Devir ve onay hataları olay günlüğüne yazılır.
- AfuTube: biten indirmenin klasörünü açma ve paylaşma (#84).

## Değişenler
- Uzantı Chrome indirmesini önce duraklatır, yalnız AfuDM devri onaylayınca iptal eder; hata, zaman aşımı veya AfuDM kapalıysa Chrome devam eder.
- Aynı indirme için tekrarlanan tarayıcı olayları tek AfuDM indirmesi oluşturur.
- Tarayıcı istekleri yalnız indirme penceresinde sorulur, iki kez sorulmaz.

## Düzeltilenler
- Tarayıcı indirmesinde ana panel artık öne gelmiyor.
- Chrome ve AfuDM aynı dosyayı birlikte indirebiliyordu.
- Uzantısız PDF bağlantıları `.pdf` olmadan kaydediliyordu; artık sunucudaki dosya adı kullanılıyor.
- İndirme penceresini X ile kapatmak isteği silmiyor; yalnız "Vazgeç" iptal eder.
- AfuDM kapatılınca veya güncelleme uygulanınca uygulama tamamen kapanıyor.
- Uzantı, AfuDM beklerken "sıraya alındı" yerine "klasörü seçin" diyor (#88).
- Hata mesajı hiçbir zaman boş dönmüyor; biten indirmeyi duraklatmak hata vermiyor (#87).
- AfuTube: dikey video kalitesi, günlük güncelleme kontrolü ve hata raporu düzeltmeleri (#86, #89).

## Güvenlik
- Bekleyen tarayıcı indirmelerinin çerez, başlık ve tarayıcı kimliği yalnız bellekte tutulur, diske yazılmaz.

## Bilinen Sorunlar
- Yeniden başlatmadan sonra, tarayıcı oturumu gerektiren bekleyen bir indirmenin tarayıcıdan tekrar gönderilmesi gerekebilir.

## Kurulum
1. `AfuDM-v2.9.0-win64.zip` dosyasını indirip aşağıdaki SHA-256 ile doğrulayın.
2. İstediğiniz yere çıkarıp `AfuDM.exe`'yi çalıştırın (taşınabilir, kurulum yok).
3. Yeni devir davranışı için AfuDM tarayıcı uzantısını yeniden yükleyin.
