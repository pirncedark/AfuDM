# AfuDM v1.9.0 — Rules Engine

AfuDM v1.9.0 introduces the visual Rules Engine, allowing domain-specific download rules and naming templates to be managed directly within the UI instead of raw JSON editing.

## Highlights

- Visual Rules Engine for domain rules and URL simulators.
- Traceability: Effective value sources are now explicitly indicated.
- i18n synchronization: TR and EN languages now have 488 identical translation keys.
- Main v1.8.0 merge conflicts were fully resolved for a clean release.

## Added

- Visual Rules Editor with drag-and-drop conditions.
- URL Simulator to test download behaviors before activation.
- `Effective Source` indicator for settings and rules.

## Changed

- Unified i18n dictionary (488 keys parity).

## Fixed

- Resolved all main v1.8.0 merge conflicts.
- All test suites (35 tests) are passing.

## Security

- No security-specific changes in this release.

## Known Issues

- No known release-blocking issues.

## Install

Download the Windows zip, extract it, and run `AfuDM.exe`.
