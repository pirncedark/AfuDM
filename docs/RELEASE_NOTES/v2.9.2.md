# AfuDM v2.9.2 — Automatic Updates, File Repair & Single Download Window

AfuDM downloads official updates automatically and installs them when transfers and pending confirmations finish. Settings, download history, downloaded files and separately added engines are preserved.

## Highlights

- Automatic updates enabled by default, with an opt-out in Settings.
- Scan completed downloads and repair damaged blocks in place using a new link.
- Browser file clicks, including opaque download links, open a single AfuDM download window.
- See remaining size, average speed and elapsed time alongside download progress.

## Added

- Automatic download and idle-time installation of official release updates, with persistent verification of staged files.
- Individual and bulk integrity scans, plus repair of damaged blocks without deleting the downloaded file.
- An Update link action in the download context menu to replace expired links and resume in place.
- Remaining size, average speed and elapsed-time statistics in the list and download window.

## Changed

- Updates give a short notice before restarting; active transfers, pending confirmations and open dialogs postpone installation.
- Automation settings are accessible in Settings; prior update opt-outs remain respected.
- Video download failures show a short explanation and an action to try.
- Unsupported plugin rollback controls are disabled with an explanation.

## Fixed

- Cached update checks no longer hide a pending update on the next launch.
- Duplicate pending requests and concurrent additions of the same normalized URL no longer create duplicate downloads.
- Interrupted, stale and resumable partial browser downloads no longer trigger unwanted handoff windows on Chrome startup.
- File clicks are intercepted before Chrome starts downloading, including links without a recognizable file extension; duplicate prompts are prevented.
- The download window keeps its Close button visible and avoids unwanted scrollbars.
- Download confirmation remains retryable after failure; failed removals remain visible and bulk removal reports actual successes.
- Link-grabber selection follows the filtered list; interface refreshes do not overlap and mobile torrent dialogs ignore stale responses.
- Torrent previews stay out of the download list, cancellation cleans up related preview jobs, and selected files follow the final torrent job.
- Download-folder changes reach the engine; file deletion is constrained to the download's own folder and preserves external source torrent files.
- Automation move/rename steps retain the correct path after restart and power actions report failures.
- Chrome extension pairing and guided installation handle connection failures and timeouts more reliably.
- Video merging preserves existing output files, writes through a temporary file and handles MP4 timing offsets correctly.
- Local API request validation and partial-file serving are more robust; diagnostic data masks secrets and proxy credentials.
- The repair action now has both Turkish and English labels.

## Security

- Updates use this repository's release assets and SHA-256 checksums.
- A failed verification or a modified staged package cannot be installed.
- Older or same-version packages are rejected.

## Known Issues

- Chrome unpacked extensions may need to be reloaded after updating their files.
- Extensions from old test folders must be disabled to avoid connecting to the wrong AfuDM copy.
- Plugin rollback is not supported.
- The separate AfuTube Android torrent/magnet work in this repository is work in progress, not verified on a device, and is not a new desktop feature in this release.

## Install

Extract the Windows ZIP and launch AfuDM.exe. Existing v2.8.0–v2.9.1 installations can use their in-app Update button once to gain automatic installation for future releases. Earlier versions without the updater require a one-time manual upgrade. Existing opt-outs are respected.

## Türkçe

AfuDM resmi güncellemeleri otomatik indirir; indirmeler ve bekleyen onaylar bitince kurar. Ayarlar, indirme geçmişi, indirilen dosyalar ve sonradan eklenen motorlar korunur.

### Öne çıkanlar

- Otomatik güncelleme varsayılan olarak açıktır; Ayarlar'dan kapatılabilir.
- Tamamlanan indirmeleri tarayın ve yeni bir linkle bozuk kısımları dosyayı silmeden onarın.
- Tarayıcıdaki dosya tıklamaları, dosya uzantısı görünmeyen linkler dahil, tek AfuDM indirme penceresine aktarılır.
- İndirme ilerlemesiyle birlikte kalan boyut, ortalama hız ve geçen süre gösterilir.

### Eklenenler

- Resmi güncellemeleri otomatik indirme ve boşta kurma; bekleyen güncelleme dosyalarının kalıcı doğrulaması.
- Tek dosya ve toplu bütünlük taraması; indirilen dosyayı silmeden bozuk blokları onarma.
- Süresi dolmuş linki değiştirip indirmeyi kaldığı yerden sürdüren sağ tık menüsündeki Linki güncelle işlemi.
- Listede ve indirme penceresinde kalan boyut, ortalama hız ve geçen süre bilgileri.

### Değişenler

- Yeniden başlatmadan önce kısa bildirim gösterilir; aktif indirmeler, bekleyen onaylar ve açık iletişim kutuları kurulumu erteler.
- Otomasyon ayarlarına Ayarlar'dan erişilebilir; otomatik güncellemeyi önceden kapatanların seçimi korunur.
- Video indirme hataları kısa açıklama ve denenebilecek bir işlem gösterir.
- Desteklenmeyen eklenti sürümüne geri dönme düğmeleri açıklamayla devre dışıdır.

### Düzeltilenler

- Önbellekteki güncelleme kontrolü, sonraki açılışta bekleyen güncellemeyi gizlemez.
- Aynı normalleştirilmiş adresin bekleyen veya eşzamanlı istekleri yinelenen indirme oluşturmaz.
- Kesilmiş, eski ve sürdürülmeye uygun kısmi tarayıcı indirmeleri Chrome açılışında gereksiz aktarım penceresi açmaz.
- Dosya tıklamaları Chrome indirmeden önce yakalanır; tanınabilir uzantısı olmayan linkler çalışır ve çift onay engellenir.
- İndirme penceresinin Kapat düğmesi görünür kalır; gereksiz kaydırma çubukları oluşmaz.
- Başarısız indirme onayı tekrar denenebilir; silinemeyen kayıtlar görünür kalır ve toplu silme gerçek başarı sayısını gösterir.
- Link yakalama seçimi filtrelenmiş listeyi izler; arayüz yenilemeleri çakışmaz ve mobil torrent pencereleri eski yanıtları yok sayar.
- Torrent önizlemeleri indirme listesine karışmaz; iptal ilgili önizleme işlerini temizler ve dosya seçimleri son torrent işine aktarılır.
- İndirme klasörü değişiklikleri motora uygulanır; silme indirmenin kendi klasörüyle sınırlıdır ve dışarıdaki kaynak torrent dosyaları korunur.
- Otomasyonun taşıma/adlandırma adımları yeniden başlatma sonrasında doğru yolu korur; güç işlemleri hataları bildirir.
- Chrome eklentisi eşleştirmesi ve yönlendirmeli kurulum bağlantı hatalarıyla zaman aşımını daha güvenilir yönetir.
- Video birleştirme mevcut çıktıları korur, geçici dosyaya yazar ve MP4 zamanlama farklarını doğru işler.
- Yerel API istek doğrulaması ve kısmi dosya sunumu iyileştirildi; tanılama verilerinde sırlar ve proxy kimlik bilgileri maskelenir.
- Onarma işleminin Türkçe ve İngilizce etiketleri tamamlandı.

### Güvenlik

- Güncellemeler bu deponun resmi yayın dosyalarını ve SHA-256 doğrulamasını kullanır.
- Doğrulanamayan veya sonradan değiştirilmiş güncelleme paketi kurulmaz.
- Eski ve aynı sürüm paketleri reddedilir.

### Bilinen sorunlar

- Chrome'un klasörden yüklenen eklentisinin güncelleme sonrasında yeniden yüklenmesi gerekebilir.
- Yanlış AfuDM kopyasına bağlanmamak için eski test klasörlerindeki eklentileri devre dışı bırakın.
- Eklenti sürümüne geri dönme desteklenmez.
- Bu depodaki ayrı AfuTube Android torrent/magnet çalışması devam etmektedir ve cihazda doğrulanmamıştır; bu yayının yeni masaüstü özelliği değildir.

### Kurulum

Windows ZIP dosyasını çıkarıp AfuDM.exe'yi açın. v2.8.0–v2.9.1 sürümlerinde uygulamadaki Güncelle düğmesine bir kez basarak sonraki yayınlar için otomatik kuruluma geçebilirsiniz. Güncelleyicisi olmayan eski sürümlerde bir kez elle yükseltme gerekir. Otomatik güncellemeyi önceden kapatanların seçimi korunur.
