# AfuDM v2.9.2 — Automatic Updates & Single Download Window

AfuDM can now download and install official updates automatically. Installation waits until transfers and pending download confirmations finish, preserving your settings and download history.

## Highlights

- Automatic updates enabled by default, with an opt-out in Settings.
- A short notice before restarting; open dialogs postpone automatic installation.
- Browser file clicks, including opaque download links, are handed to AfuDM before Chrome starts its own download.
- The download window's Close button remains visible.

## Added

- Automatic download and idle-time installation of official release updates.
- Persistent verification of staged update files before replacement.

## Fixed

- Cached update checks no longer hide a pending update on the next launch.
- Active downloads and pending confirmations prevent update-driven restarts.
- Opaque browser file links and the clipped Close button are handled correctly.

## Security

- Updates use this repository's release assets and SHA-256 checksums.
- A failed verification or a modified staged package cannot be installed.
- Older or same-version packages are rejected.

## Install

Extract the Windows ZIP and launch AfuDM.exe. Existing v2.8.0–v2.9.1 installations can use their in-app Update button once to gain automatic installation for future releases. Earlier versions without the updater require a one-time manual upgrade. Existing opt-outs are respected.

## Known Issues

- Chrome unpacked extensions may need to be reloaded after updating their files.
- Extensions from old test folders must be disabled to avoid connecting to the wrong AfuDM copy.
