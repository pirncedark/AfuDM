# AfuDM v2.7.4 — Instant Pause & Resume

This patch release makes pause and resume respond immediately, including for torrents that have already finished.

## Highlights
- Duraklatma ve sürdürme işlemleri arayüzde anında uygulanır; işlem başarısız olursa durum geri alınır ve tek cümlelik hata gösterilir.
- Tamamlanmış torrentlerde duraklatma için `forcePause` kullanılır.
- Arayüz kapısı testindeki yarış durumu giderildi (#67); bu yalnızca test düzeltmesidir.

## Fixed
- PR #68: Tamamlanmış torrentlerde duraklatma ve anında yanıt veren iyimser arayüz güncellemesi; hata durumunda geri alma.
- PR #67: UI gate testindeki yarış durumu düzeltildi.
