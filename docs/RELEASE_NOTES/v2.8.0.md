# AfuDM v2.8.0 — In-App Updates & AfuTube Sharing

AfuDM can now check GitHub Releases for updates and install them with one click. AfuTube can share downloaded videos with WhatsApp, WhatsApp Business, or the system share menu. Failed update checks do not start the 24-hour wait before another check.

## Highlights
- Check for a new AfuDM release and download and install it from within the app.
- Share downloaded AfuTube videos through WhatsApp, WhatsApp Business, or the system share menu.
- Strengthened the CI and push workflow with pre-commit, gitleaks, commitizen, release-please, and pinned GitHub Actions.

## Added
- In-app update check and installation from this project's GitHub Releases. Failed checks do not start the 24-hour cooldown (#82).
- AfuTube video sharing to WhatsApp, WhatsApp Business, and the Android system share menu (#83).

## Changed
- Added pre-commit, gitleaks, commitizen, quality checks, and release-please to the contribution and release workflow (#69).
- Pinned GitHub Actions and tightened workflow permissions (#73).
- Aligned release-please with version-prefixed tags and `core/surum.py` (#70).

## Fixed
- A failed update check no longer starts the 24-hour wait before the next check (#82).
- Release version handling now matches version-prefixed tags (#70).

## Security
- Updates are accepted only from this project's release URLs, checked against SHA-256, and rejected if the archive contains unsafe paths. The update process can roll back if installation fails (#82).
- GitHub Actions are pinned and workflow permissions are tightened (#73).

## Known Issues
- No known issues are documented for this release.

## Install
1. Download `AfuDM-v2.8.0-win64.zip` and verify it against the SHA-256 below.
2. Extract it anywhere and run `AfuDM.exe` (portable, no installer).
