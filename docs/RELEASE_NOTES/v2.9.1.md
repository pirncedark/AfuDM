# AfuDM v2.9.1 — Reliable Local API Startup

Local API startup no longer waits for reverse DNS, so unavailable DNS cannot stall the HTTP listener. The download window now keeps its native window and parent application objects out of the JavaScript bridge. This prevents pywebview from recursively inspecting those objects while preparing the download window.

## Highlights
- DNS-independent local API startup and safe download window initialization.

## Added
- A regression test that blocks reverse DNS in both local and LAN modes and verifies a real HTTP ping response.
- A regression test using pywebview's real bridge generator to check that native objects and parent-only methods are not exposed.

## Fixed
- HTTPServer initialization synchronously resolved the listener hostname before starting request handling; numeric listeners now bind without reverse DNS.
- Public download window references allowed the bridge generator to walk into the native window object and expose the parent API.

## Known Issues
- The historical v2.9.0 executable hang did not reproduce in isolated probes. Both DNS-dependent startup blocking and unsafe bridge traversal are independently reproduced and corrected; the exact trigger of that historical incident remains unconfirmed.
- Pending downloads requiring a browser login may need to be sent again after a restart.

## Install
1. Download `AfuDM-v2.9.1-win64.zip` and verify the SHA-256 below.
2. Extract the portable package and run `AfuDM.exe`.
3. Reload the browser extension.

- Yerel ve ağ modlarında ters DNS beklemesini taklit edip gerçek HTTP ping yanıtını doğrulayan regresyon testi.

- İndirme penceresindeki açık nesne başvuruları, köprü üreticisinin yerel pencere nesnesine girmesine ve ana API'yi açmasına yol açıyordu.
