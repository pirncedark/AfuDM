# AfuDM v2.6.0 — API Bridge Robustness & Engine Connection Stability

This release hardens the desktop API bridge and engine snapshot polling to resolve false "no connection" (`bağlantı yok`) error states and pywebview `AttributeError` exceptions when inspecting bridge attributes.

## Highlights
- **API Bridge Protection:** Class-level default attribute fallbacks (`_window`, `_baslik_dili`, `_windows`) added to the `Api` bridge class so uninitialized properties never raise `AttributeError`.
- **Property Accessor Security:** `Api.windows` is now a safe property accessor returning `None` if Windows integration is disabled or uninitialized.
- **Resilient Engine Snapshot Polling:** `Api.snapshot()` now isolates window title synchronization in a protected exception handler, preventing any title sync or bridge error from breaking periodic engine status ticks.
- **HTTP Server Protections:** HTTP API route handlers for `/windows-integration` now use safe attribute inspection (`getattr(manager, "windows", None)`).
- **Core Manager Reliability:** `Manager.__init__` gracefully handles Windows integration initialization failures, falling back safely on non-supported platforms or restricted permission environments.

## Added
- Safe `Api.windows` property getter/setter with fallback to `manager.windows`.
- Graceful exception recovery around `_basligi_esitle()` in `Api.snapshot()`.

## Changed
- `SURUM` updated to `2.6.0` in `core/surum.py` and `extension/manifest.json`.
- PyInstaller executable rebuilt with latest core protections.

## Türkçe

Bu sürüm, masaüstü API köprüsünü ve motor snapshot sorgulamasını güçlendirerek hatalı "bağlantı yok" durumlarını ve pywebview nitelik incelemelerinde ortaya çıkan `AttributeError` istisnalarını çözer.

## Öne Çıkanlar
- **API Köprüsü Koruması:** `Api` sınıfına sınıf düzeyinde varsayılan nitelikler (`_window`, `_baslik_dili`, `_windows`) eklendi; başlatılmamış özellikler artık `AttributeError` vermez.
- **Güvenli Nitelik Erişimi:** `Api.windows`, Windows entegrasyonu kapalı veya başlatılmamışsa güvenle `None` dönen bir `property` haline getirildi.
- **Dayanıklı Motor Snapshot Dönüşü:** `Api.snapshot()` içindeki pencere başlığı senkronizasyonu özel istisna yöneticisiyle izole edildi; başlık senkronizasyonu hatası motor durum sorgularını asla bozmaz.
- **HTTP Sunucu Koruması:** HTTP API `/windows-integration` rotaları güvenli `getattr` denetimine alındı.
- **Yönetici Kararlılığı:** `Manager.__init__` Windows entegrasyonu başlatma hatalarını güvenle ele alır, desteklenmeyen platformlarda veya yetki kısıtlarında çökmeden devam eder.

## Eklenenler
- `manager.windows` düşüşünü yöneten güvenli `Api.windows` `property` getter/setter'ı.
- `Api.snapshot()` içinde `_basligi_esitle()` çağrısı etrafında istisna telafisi.

## Değişenler
- `core/surum.py` ve `extension/manifest.json` dosyalarında sürüm `2.6.0` olarak güncellendi.
- `AfuDM.exe` en güncel çekirdek korumalarıyla yeniden derlendi.
