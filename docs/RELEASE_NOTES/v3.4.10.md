# AfuDM v3.4.10 — Reliable Torrent Retries and Faster List Refresh

This release keeps the user's torrent file selection when a download is retried, hardens the download queue against several race conditions found in a full bug audit, and refreshes the download list promptly on startup and after new additions.

## Highlights
- Retrying a torrent downloads only the files the user selected, not the whole torrent.
- The download list appears right after startup and updates as soon as a download is added.
- Tracker scans now really apply the found trackers; trackers can also be added manually.

## Added
- "Add tracker" action in the row context menu and a matching endpoint.

## Changed
- Partial torrent selections use `file-allocation=none`, and unselected neighbour files are cleaned up.
- Windows Controlled Folder Access errors show a readable message.

## Fixed
- Torrent retry no longer drops the file selection.
- Stale error state is cleared when a download becomes active or waiting again.
- Magnet reattach, pause/remove race, worker retry limits, orphan database rows, update shutdown cleanup, UNC paths, endpoint port 0, Explorer `/select` and blob file types.
- The download list no longer appears late after startup or after adding a download.

## Security
- No security-related changes in this release.

## Known Issues
- None known.

## Install
- Use the in-app update when available, or download the Windows x64 package from the release assets.

## Türkçe

Bu sürüm, yeniden denenen torrent indirmesinde kullanıcının dosya seçimini korur, tam hata taramasında bulunan kuyruk yarış durumlarını giderir ve indirme listesini açılışta ve yeni ekleme sonrası hemen yeniler.

## Öne Çıkanlar
- Torrent yeniden denendiğinde yalnız seçilen dosyalar iner, bütün torrent değil.
- İndirme listesi açılıştan hemen sonra görünür ve yeni indirme eklenince anında güncellenir.
- Tracker taraması bulunan tracker'ları gerçekten uygular; tracker elle de eklenebilir.

## Eklenenler
- Satır menüsünde "Tracker ekle" eylemi.

## Değişiklikler
- Kısmi torrent seçiminde `file-allocation=none` kullanılır, seçilmeyen komşu dosyalar temizlenir.
- Windows Denetimli Klasör Erişimi hatası okunur bir mesajla gösterilir.

## Düzeltilenler
- Torrent yeniden denemesi dosya seçimini kaybetmez.
- İndirme yeniden etkin ya da bekler duruma geçince eski hata temizlenir.
- Magnet yeniden bağlama, duraklat/kaldır yarışı, işçi yeniden deneme sınırı, sahipsiz veritabanı satırları, güncelleme kapanış temizliği, UNC yolları, port 0, Explorer `/select` ve blob dosya türleri.
- İndirme listesi açılışta ve ekleme sonrası geç görünmez.

## Güvenlik
- Bu sürümde güvenlik değişikliği yok.

## Bilinen Sorunlar
- Bilinen sorun yok.

## Kurulum
- Uygulama içi güncelleme çıktığında kullanın veya release varlıklarından Windows x64 paketini indirin.
