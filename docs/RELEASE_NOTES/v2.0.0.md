# AfuDM v2.0.0 — Plugin Platform

AfuDM v2.0.0 introduces the plugin platform. Plugins ship as `.afup` packages, are installed from the UI after an explicit permission review, and run in a separate process so a crashing or hanging plugin cannot take down AfuDM. This release uses a **trusted plugin** model: the separate process provides fault isolation, not a security sandbox.

## Highlights

- `.afup` plugin packages: install, update, enable/disable and remove from the UI.
- Plugins run in a separate host process — a crash or hang no longer affects AfuDM.
- Permission and domain review screen shown before every installation.
- Automatic rollback to the previous version when an update fails.
- Per-plugin activity log and a live operation indicator.

## Added

- Plugin registry (`plugins` table) with version, source, permissions, domains and settings.
- Separate-process plugin host with timeout and hang protection.
- Plugin manifest contract (`docs/EKLENTI_MANIFEST.md`).
- HTTP endpoints: `/eklentiler`, `/eklenti/gunluk`, `/eklenti/islem`.
- `tests/eklenti_test.py` covering installation, rejection, update, rollback and Zip Slip.

## Changed

- Database schema raised to `user_version = 8`. The plugin migration was moved from slot 4 to slot 8 because slot 4 was already taken by the v1.7.5 / v1.8 history.
- Extension manifest version aligned with the application version.

## Fixed

- Resolved all v1.9.0 merge conflicts in `api/server.py`, `core/db.py`, `core/manager.py` and `ui/style.css`.
- Upgrades from any earlier schema version reach `user_version = 8` with no table left behind.

## Security

- Zip Slip is blocked: archive entries that try to write outside the plugin folder are rejected.
- The permission list is shown before installation and is explicitly labelled as the plugin's **own declaration**. AfuDM does not technically enforce it — this is stated in the UI.
- This release is a trusted plugin model. Install only plugins whose source you trust.

## Known Issues

These are known and deliberately shipped; they are scheduled for v2.3 Reliability & Security:

- **No archive size limit.** Extraction has no cap on uncompressed size, so a malicious `.afup` can exhaust disk space (zip bomb). Path traversal is blocked, size is not.
- **No SHA-256 verification.** Package integrity is not verified at install time.
- **Permissions are not enforced at runtime.** They are displayed for review only.
- **No manual rollback in the UI.** Rollback happens automatically on a failed update, but cannot be triggered by the user.

## Install

Download the Windows zip, extract it, and run `AfuDM.exe`.

## Türkçe

AfuDM v2.0.0 eklenti platformunu getiriyor. Eklentiler `.afup` paketi olarak dağıtılır, arayüzden açık bir izin incelemesinden sonra kurulur ve ayrı bir süreçte çalışır; böylece çöken veya takılan bir eklenti AfuDM'i etkilemez. Bu sürüm **güvenilen eklenti** modelini kullanır: ayrı süreç hata yalıtımı sağlar, güvenlik kum havuzu (sandbox) DEĞİLDİR.

### Öne çıkanlar

- `.afup` eklenti paketleri: arayüzden kurma, güncelleme, etkinleştirme/pasifleştirme ve kaldırma.
- Eklentiler ayrı bir host sürecinde çalışır — çökme veya takılma AfuDM'i etkilemez.
- Her kurulumdan önce izin ve alan adı inceleme ekranı.
- Güncelleme başarısız olursa önceki sürüme otomatik geri dönüş.
- Eklenti başına etkinlik günlüğü ve canlı işlem göstergesi.

### Eklendi

- Eklenti kayıt defteri (`plugins` tablosu): sürüm, kaynak, izinler, alan adları ve ayarlar.
- Zaman aşımı ve takılma korumalı ayrı süreç eklenti host'u.
- Eklenti manifest sözleşmesi (`docs/EKLENTI_MANIFEST.md`).
- HTTP uçları: `/eklentiler`, `/eklenti/gunluk`, `/eklenti/islem`.
- `tests/eklenti_test.py` — kurulum, ret, güncelleme, rollback ve Zip Slip vakaları.

### Değişti

- Veritabanı şeması `user_version = 8`'e çıktı. Eklenti migration'ı 4 numaralı slottan 8'e taşındı; 4 numara v1.7.5 / v1.8 geçmişi tarafından zaten kullanılmıştı.
- Uzantı manifest sürümü uygulama sürümüyle hizalandı.

### Düzeltildi

- `api/server.py`, `core/db.py`, `core/manager.py` ve `ui/style.css` içindeki tüm v1.9.0 merge çakışmaları çözüldü.
- Daha eski her şema sürümünden yükseltme `user_version = 8`'e ulaşıyor, geride tablo kalmıyor.

### Güvenlik

- Zip Slip engellendi: eklenti klasörü dışına yazmaya çalışan arşiv girdileri reddedilir.
- İzin listesi kurulumdan önce gösterilir ve bunun eklentinin **kendi beyanı** olduğu açıkça yazılır. AfuDM bu listeyi teknik olarak zorlamaz; bu durum arayüzde belirtilmiştir.
- Bu sürüm güvenilen eklenti modelidir. Yalnızca kaynağına güvendiğin eklentileri kur.

### Bilinen sorunlar

Bunlar bilinerek bu sürümde bırakıldı; v2.3 Reliability & Security'ye planlandı:

- **Arşiv boyut sınırı yok.** Açma işleminde sıkıştırılmamış boyut sınırlanmıyor; kötü niyetli bir `.afup` diski doldurabilir (zip bomb). Yol geçişi engelli, boyut değil.
- **SHA-256 doğrulaması yok.** Paket bütünlüğü kurulum sırasında doğrulanmıyor.
- **İzinler çalışma zamanında zorlanmıyor.** Yalnızca incelenmek üzere gösteriliyor.
- **Arayüzde manuel rollback yok.** Geri dönüş yalnızca başarısız güncellemede otomatik olur, kullanıcı tetikleyemez.

### Kurulum

Windows zip dosyasını indir, arşivi çıkar ve `AfuDM.exe` dosyasını çalıştır.
