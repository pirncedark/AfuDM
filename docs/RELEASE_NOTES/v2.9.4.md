# AfuDM v2.9.4 — Browser Handoff & Retry Fixes

This release fixes three download problems: browser links that opened a quality-picker page now stay normal pages, "Retry" no longer leaves a second failed row, and ChatGPT/blob/small browser downloads now go to AfuDM. It also includes everything from v2.9.3.

## Highlights

- Generic `/download/<id>` pages (quality pickers, countdowns) are no longer sent to AfuDM as an HTML file.
- "Retry" restarts the same download; no duplicate failed row stays in the list.
- ChatGPT, blob and small browser downloads are handed to AfuDM, with auto-accept on by default.

## Fixed

- Click interception treats only the opaque `/dosya/f/<id>` endpoint as an extensionless file link; real downloads on other URLs are still handed over by Chrome's download event.
- After Retry, the engine's old error record is removed and hidden, so the same file name is not listed twice.
- Link renewal called a non-existent engine function whose error was swallowed; it now cleans up the old result correctly.

## Install

Download `AfuDM-v2.9.4-win64.zip`, extract it and run `AfuDM.exe`. Existing installs update automatically.

## Türkçe

Bu sürüm üç indirme sorununu düzeltir: kalite seçtiren sayfalar artık normal sayfa olarak açılır, "Yeniden dene" ikinci bir hatalı satır bırakmaz, ChatGPT/blob/küçük tarayıcı indirmeleri AfuDM'e gider. v2.9.3'teki her şeyi de içerir.

## Öne çıkanlar

- `/download/<id>` gibi genel sayfalar (kalite seçimi, geri sayım) artık AfuDM'e HTML dosyası olarak gönderilmez.
- "Yeniden dene" aynı indirmeyi yeniden başlatır; listede ikinci hatalı satır kalmaz.
- ChatGPT, blob ve küçük tarayıcı indirmeleri AfuDM'e devredilir; otomatik kabul varsayılan olarak açık.

## Düzeltilenler

- Tıklama yakalama yalnız `/dosya/f/<id>` uzantısız dosya adresini dosya sayar; diğer adreslerdeki gerçek indirmeleri Chrome'un indirme olayı yine devreder.
- Yeniden denemeden sonra motorun eski hata kaydı silinip gizlenir; aynı dosya adı iki kez listelenmez.
- Link yenileme, var olmayan bir motor fonksiyonunu çağırıyordu ve hata gizleniyordu; artık eski sonucu doğru temizler.
