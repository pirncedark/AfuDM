# AfuDM v2.9.5 — Accurate Integrity Scan & Update Now

This release removes false "damaged block" alarms on healthy archives and stops the update bar from waiting forever on a hidden download approval.

## Highlights

- Healthy RAR/ZIP downloads are no longer reported as "N blocks damaged".
- Leftover `.aria2` control files of finished downloads are cleaned up.
- The update bar says why it is waiting and offers "Update now" when only an approval is pending.

## Fixed

- The integrity scan treated a 4 MB block of compressed data as a JSON/HTML error page when it happened to start with `{` or `<`. Text checks now require a readable-text block head. Verified on six 2.6–9.9 GB RARs that were wrongly flagged.
- A finished download with a complete `.aria2` control file is no longer reported as "incomplete"; the leftover file is removed after a clean scan. A control file with missing pieces is still treated as incomplete.
- The update stayed disabled when a browser download approval was pending out of sight. The app now reports whether it waits for active transfers or an approval; for an approval, the button becomes "Update now". Active transfers still block updating, and automatic updates never skip an approval.

## Install

Download `AfuDM-v2.9.5-win64.zip`, extract it and run `AfuDM.exe`. Existing installs update automatically.

## Türkçe

Bu sürüm sağlam arşivlerde çıkan sahte "bozuk blok" uyarılarını kaldırır ve görünmeyen bir indirme onayı yüzünden güncelleme çubuğunun sonsuza dek beklemesini önler.

## Öne çıkanlar

- Sağlam RAR/ZIP indirmeleri artık "N blok bozuk" diye bildirilmez.
- Biten indirmelerin yanında kalan `.aria2` kontrol dosyaları temizlenir.
- Güncelleme çubuğu neden beklediğini söyler; yalnız bir onay bekliyorsa "Şimdi güncelle" düğmesi çıkar.

## Düzeltilenler

- Bütünlük taraması, `{` veya `<` ile başlayan 4 MB'lık sıkıştırılmış veri bloğunu JSON/HTML hata sayfası sanıyordu. Artık blok başının okunur metin olması gerekir. Yanlış işaretlenen altı 2,6–9,9 GB'lık RAR'da doğrulandı.
- Tüm parçaları inmiş `.aria2` kontrol dosyası olan biten indirme artık "eksik" sayılmaz; temiz taramadan sonra artık dosya silinir. Eksik parçalı kontrol dosyası yine yarım sayılır.
- Görünmeyen bir tarayıcı indirme onayı beklerken güncelleme düğmesi pasif kalıyordu. Uygulama artık aktif indirme mi onay mı beklediğini bildirir; onay ise düğme "Şimdi güncelle" olur. Aktif indirme yine güncellemeyi engeller, otomatik güncelleme onayı atlamaz.
