# AfuDM v3.4.9 — Reliable Folder Opening and Browser Handoff

This release improves Explorer folder selection for paths with spaces and Unicode characters, opens the torrent's own folder when available, and keeps browser handoff requests responsive while the user confirms a destination. Handoff failures are classified without storing URLs or credentials, and their notifications offer a direct next action.

## Highlights
- Explorer opens the correct download or torrent folder, including paths with spaces and Turkish characters.
- Browser handoff returns immediately while the destination prompt stays in AfuDM.
- Handoff failures produce short, actionable notifications and safe diagnostic log entries.

## Added
- Error-class logging for browser handoff failures without persisting sensitive request details.
- Notification actions to open AfuDM or retry from the extension.

## Changed
- Explorer command arguments explicitly quote folder and selected-file paths.
- Missing download paths fall back to the torrent folder, saved destination, or download folder.

## Fixed
- Multi-file torrent folder actions open the torrent directory when it exists.
- Interactive browser downloads no longer wait for the save-location prompt before receiving an acknowledgment.
- A single slow aria2 health check no longer marks the engine as stopped; the app waits for repeated failures before showing a stopped state and requesting one automatic restart.

## Security
- Handoff diagnostics store only a fixed error category; URLs, cookies, headers, and raw error text are not recorded.

## Known Issues
- Live Chrome and installed-app verification must be completed before publication.
- Engine health grace and automatic restart behavior are covered by Rust tests; live engine and second-instance application verification remain pending.

## Install
- Use the in-app update when available, or download the Windows x64 package from the release assets.

## Türkçe

Bu sürüm, boşluk ve Türkçe karakter içeren yolların Explorer'da doğru açılmasını sağlar. Torrent klasörü varsa doğrudan onu açar. Tarayıcı indirme devri, kullanıcı hedef klasörü onaylarken beklemez; hata bildirimleri kısa ve uygulanabilir olur.

## Öne Çıkanlar
- Explorer, indirme veya torrent klasörünü doğru açar.
- Tarayıcı devri, AfuDM'deki hedef klasör onayı sırasında yanıt vermeye devam eder.
- Hata bildirimleri ne olduğunu ve sonraki adımı kısa biçimde söyler.

## Eklenenler
- Hassas istek ayrıntılarını saklamayan hata türü günlük kaydı.
- AfuDM'i açan veya eklenti üzerinden yeniden denemeyi sağlayan bildirim eylemleri.

## Değişiklikler
- Explorer'a klasör ve seçili dosya yolları açık tırnaklamayla gönderilir.
- Yol bulunamazsa torrent klasörü, kayıt hedefi veya indirme klasörü açılır.

## Düzeltilenler
- Çok dosyalı torrentlerde klasör eylemi, mevcutsa torrentin kendi klasörünü açar.
- Etkileşimli tarayıcı indirmeleri, klasör onay penceresini beklerken zaman aşımına uğramaz.
- Tek bir yavaş aria2 sağlık kontrolü motoru kapalı göstermez; uygulama kapalı durumu göstermeden ve bir kez otomatik yeniden başlatma istemeden önce art arda hataları bekler.

## Güvenlik
- Tanılama kaydı yalnız sabit hata sınıfını tutar; URL, çerez, başlık veya ham hata metni kaydedilmez.

## Bilinen Sorunlar
- Yayın öncesi gerçek Chrome ve kurulu uygulama doğrulaması tamamlanmalıdır.
- Motor toleransı ve otomatik yeniden başlatma davranışı Rust testleriyle kapsanır; canlı motor ve ikinci uygulama örneği doğrulaması beklemededir.

## Kurulum
- Uygulama içi güncelleme çıktığında kullanın veya release varlıklarından Windows x64 paketini indirin.
