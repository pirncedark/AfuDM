# AfuDM v2.1.0 — Headless Server

AfuDM v2.1.0 lets the application run without its desktop window. `afuadm server` starts the core with an HTTP management API and a browser panel, so a Windows home server, a NAS-attached machine or a spare PC can run AfuDM and be managed from any device on the same network. The server is **off by default** and nothing is reachable without a key.

## Highlights

- Headless runtime: AfuDM core runs with no UI (`headless.py`, `afuadm server`).
- Web management panel served by the application itself.
- Access keys with roles: read-only, write, settings and manage.
- Server profiles, connected-client list and revocable keys.
- Off by default, local-only unless LAN mode is explicitly chosen.

## Added

- Access layer with `secrets`-generated keys, roles and revocation (`core/erisim.py`).
- HTTP management API and browser panel (`api/web.py`, `ui/panel.html`).
- Brute-force lockout, per-IP request limiting and CSRF/origin checks.
- Desktop controls for request limit, failed-attempt limit, lock duration, allowed origins and client logging.
- `tests/headless_test.py` (21 cases) and `tests/v21_guvenlik_test.py` (8 cases).

## Changed

- Database schema raised to `user_version = 9`. The server-access migration was moved from slot 4 to slot 9, because slot 4 was already taken by earlier releases.

## Fixed

- **Remote write outside the download root.** A client with the `write` role could set the destination folder to any path on the server and download into it. Remote requests are now resolved and must stay inside the download root; anything else is rejected.
- **Absolute path disclosure.** `OSError` text was returned over the network and contained full file paths on Windows. The network response is now generic; the full message goes to the local log only.
- All v2.0.0 merge conflicts resolved.

## Security

- TLS is **not** provided. Traffic is plain HTTP. In LAN mode only devices on the same local network can reach it; exposing it to the internet is the user's own port-forwarding decision.
- Keys are generated with `secrets.token_urlsafe(32)`.
- State-changing requests require a custom CSRF header.

## Known Issues

- Behind a reverse proxy all clients share the proxy IP, so one brute-force attempt can lock everyone out. `X-Forwarded-For` is deliberately not trusted by default.
- No TLS; use it on a trusted network.

## Install

Download the Windows zip, extract it, and run `AfuDM.exe`. For headless use run `afuadm server`.

## Türkçe

AfuDM v2.1.0 uygulamanın masaüstü penceresi olmadan çalışmasını sağlar. `afuadm server` çekirdeği bir HTTP yönetim API'si ve tarayıcı paneliyle başlatır; böylece bir Windows ev sunucusu, NAS'a bağlı makine veya yedek bir bilgisayar AfuDM'i çalıştırıp aynı ağdaki her cihazdan yönetilebilir. Sunucu **varsayılan olarak kapalıdır** ve anahtarsız hiçbir şeye erişilemez.

### Öne çıkanlar

- Arayüzsüz çalışma: AfuDM çekirdeği UI olmadan çalışır (`headless.py`, `afuadm server`).
- Uygulamanın kendi sunduğu web yönetim paneli.
- Rollü erişim anahtarları: salt okur, yazma, ayar ve yönetim.
- Sunucu profilleri, bağlı istemci listesi ve iptal edilebilir anahtarlar.
- Varsayılan kapalı; LAN kipi açıkça seçilmedikçe yalnızca yerel.

### Eklendi

- `secrets` ile üretilen anahtarlar, roller ve iptal (`core/erisim.py`).
- HTTP yönetim API'si ve tarayıcı paneli (`api/web.py`, `ui/panel.html`).
- Kaba kuvvet kilidi, IP başına istek limiti ve CSRF/origin denetimi.
- Masaüstünde istek limiti, hatalı deneme limiti, kilit süresi, izinli kaynak adresler ve istemci kaydı kontrolleri.
- `tests/headless_test.py` (21 vaka) ve `tests/v21_guvenlik_test.py` (8 vaka).

### Değişti

- Şema `user_version = 9`'a çıktı. Sunucu erişimi migration'ı 4 numaralı slottan 9'a taşındı; 4 numara daha önceki sürümlerce kullanılmıştı.

### Düzeltildi

- **İndirme kökü dışına uzaktan yazma.** `yazma` rolündeki bir istemci hedef klasörü sunucudaki herhangi bir yol olarak verip oraya indirebiliyordu. Uzaktan gelen istekler artık çözümlenip indirme kökünün içinde kalmak zorunda; dışarı çıkan reddediliyor.
- **Mutlak yol sızıntısı.** `OSError` metni ağa dönüyordu ve Windows'ta tam dosya yollarını içeriyordu. Ağa dönen yanıt artık jenerik; tam metin yalnızca yerel günlüğe yazılıyor.
- Tüm v2.0.0 merge çakışmaları çözüldü.

### Güvenlik

- TLS **yoktur**. Trafik düz HTTP'dir. LAN kipinde yalnızca aynı yerel ağdaki cihazlar erişebilir; internete açmak kullanıcının kendi yönlendirme kararıdır.
- Anahtarlar `secrets.token_urlsafe(32)` ile üretilir.
- Durum değiştiren istekler özel bir CSRF başlığı ister.

### Bilinen sorunlar

- Ters vekil (reverse proxy) arkasında tüm istemciler aynı IP'yi paylaşır; tek bir kaba kuvvet denemesi herkesi kilitleyebilir. `X-Forwarded-For` bilinçli olarak varsayılan güvenilmez.
- TLS yok; güvendiğin ağda kullan.

### Kurulum

Windows zip dosyasını indir, arşivi çıkar ve `AfuDM.exe` dosyasını çalıştır. Arayüzsüz kullanım için `afuadm server`.
