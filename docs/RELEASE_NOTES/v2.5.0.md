# AfuDM v2.5.0 — Connection Stability

This release makes the desktop and mobile companions more robust: the phone UI no longer dies on a broken script, the Rules panel always opens even when the old engine has no rules bridge, the connection status no longer flickers on slow snapshots, and the version badge now reports the live build from a single source. The Windows executable also carries an embedded version resource (publisher, product name, copyright, version) so the file properties look like a real product instead of an anonymous binary.

## Highlights
- **Connection Stability:** The engine is marked offline only after 2 consecutive failures, and the snapshot timeout was raised to 30 seconds — no more flickering "no connection" on slow ticks.
- **Mobile Companion Fix:** A fatal syntax error in `mobil.html` left the phone UI as static HTML; the script is fixed and a reconnect panel (`Bağlan`) now appears when the session drops.
- **Rules Panel Always Opens:** "Kuralları yönet" now opens the panel first and loads data in the background; if the engine lacks the rules bridge, the error is shown *inside* the panel instead of silently refusing to open.
- **Real Version Badge:** The bottom-right indicator is now single-sourced from `core/surum.py` through a proper bridge method, so it shows the actual running build.
- **Product Identity:** The Windows `AfuDM.exe` now embeds a version resource (company, product, copyright, file version) — the first step toward a trusted-publisher appearance on Windows and SmartScreen reputation.

## Added
- `baglantiUyari` reconnect panel in the mobile UI with manual address entry and a reconnect button.
- `surum_bilgi` bridge method exposing the live desktop and extension versions to the UI.
- Windows version resource injected at build time, version pulled from `core/surum.py` (single source).

## Changed
- Snapshot timeout increased from 15s to 30s to tolerate heavy aria2 queries.
- Offline status now requires 2 consecutive failures before showing "no connection".
- Rules panel opens before the bridge call so it is never unreachable.
- Bottom-right corner shows a single "AfuDM vX.Y.Z" badge (the old duplicate room was removed).
- The trace/status junction keeps its seamless look (no divider below the speed readout).

## Türkçe

Bu sürüm masaüstü ve mobil eşlikçi uygulamalarını daha sağlam hale getiriyor: telefon arayüzü bozuk bir betik yüzünden artık ölmüyor, "Kuralları yönet" paneli motor eski derlemede olsa bile her zaman açılıyor, yavaş snapshot'larda bağlantı durumu artık titremiyor ve sürüm rozeti çalışan derlemeyi tek kaynaktan gösteriyor. Windows çalıştırılabilirinde ayrıca yayıncı, ürün adı, telif ve sürüm bilgileri gömülü — dosya özellikleri anonim bir betik yerine gerçek bir ürün gibi görünüyor.

## Öne Çıkanlar
- **Bağlantı Kararlılığı:** Motor yalnızca 2 ardışık hatadan sonra "bağlantı yok" olarak işaretleniyor ve snapshot zaman aşımı 30 saniyeye çıkarıldı — yavaş güncellemelerde yanıp sönen "bağlantı yok" sorunu bitti.
- **Mobil Eşlikçi Onarımı:** `mobil.html` içindeki ölümcül bir yazım hatası telefon arayüzünü statik HTML'e çeviriyordu; betik düzeltildi ve oturum düşünce "Bağlan" paneli beliriyor.
- **Kurallar Paneli Her Zaman Açılır:** "Kuralları yönet" önce paneli açıyor, veriyi arka planda yüklüyor; motor kurallar köprüsüne sahip değilse hata panelin *içinde* gösteriliyor ve panel kapalı kalmıyor.
- **Gerçek Sürüm Rozeti:** Sağ alttaki gösterge artık `core/surum.py`'den gerçek köprü metodu üzerinden besleniyor; çalışan derlemeyi gerçekten gösteriyor.
- **Ürün Kimliği:** `AfuDM.exe` artık sürüm kaynağı (şirket, ürün, telif, dosya sürümü) içeriyor — Windows'ta güvenilir yayıncı görünümü ve SmartScreen itibarı için ilk adım.

## Eklenenler
- Mobil arayüzde `baglantiUyari` yeniden bağlanma paneli (manuel adres girişi + yeniden bağlanma butonu).
- UI'ye masaüstü ve uzantı sürümünü veren `surum_bilgi` köprü metodu.
- Derleme sırasında gömülen ve `core/surum.py`'den beslenen Windows sürüm kaynağı (tek kaynak).

## Değişenler
- Snapshot zaman aşımı 15 saniyeden 30 saniyeye çıkarıldı (ağır aria2 sorgularına tolerans).
- "Bağlantı yok" durumu ancak 2 ardışık hatadan sonra gösteriliyor.
- Kurallar paneli köprü çağrısından önce açılıyor; hiçbir koşulda erişilemez olmuyor.
- Sağ alt köşede tek "AfuDM vX.Y.Z" rozeti (eski tekrar eden bölme kaldırıldı).
- İz/alan birleşimi kesintisiz görünümünü koruyor (hız okumasının altında ayırıcı yok).
