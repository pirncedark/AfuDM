# AfuDM v2.7.3 — Torrent & Drawer Fixes

This patch release fixes torrents appearing twice after being added through the save dialog, makes the file selection in that dialog actually apply, stops the detail drawer from flickering every second, and lets you resize the bottom drawer with the mouse.

## Highlights
- **One torrent, one row:** a torrent added through the save dialog no longer shows up twice (one downloading, one paused at 0 B). The paused preview used to show the file list is now reused instead of adding a second copy.
- **File selection works:** files you untick in the save dialog are really skipped. Before, every file was downloaded.
- **No more flicker:** the Files and Trackers tabs of the detail drawer no longer blink or jump on each refresh.
- **Resizable drawer:** drag the top edge of the bottom drawer to make it taller or shorter. Double-click the edge to reset. The height is remembered.

## Added
- Drag handle on the detail drawer's top edge: mouse/pen drag, ArrowUp/ArrowDown from the keyboard, double-click to reset; height is clamped to the window and kept across restarts (#65).

## Fixed
- Save dialog → torrent: the preview download and the selected files were dropped between the dialog and the download engine (both the browser-request and the add-link paths), so aria2 received the torrent a second time (#64).
- Safety net: when a torrent is added without that link, a matching paused preview with the same info hash is adopted instead of adding a duplicate; the info hash is now also read from `.torrent` files, including multi-file torrents (#64).
- Detail drawer tabs were cleared before new data arrived on every refresh, causing flicker; content is now updated in one step and only when it changed, and a failing file list shows its error once instead of every second (#65).

## Known Issues
- A duplicate row left over from an earlier version can be removed with **Remove**; in v2.7.1 removing such a row did not work (fixed since v2.7.2).

## Install
1. Download `AfuDM-v2.7.3-win64.zip` and verify it against the SHA-256 below.
2. Extract anywhere and run `AfuDM.exe` (portable, no installer).

## Türkçe

Bu yama sürümü, kaydetme penceresinden eklenen torrentlerin iki kez görünmesini düzeltir, penceredeki dosya seçimini gerçekten uygular, detay panelinin her saniye titremesini durdurur ve alt paneli fareyle büyütüp küçültmeyi sağlar.

## Öne Çıkanlar
- **Bir torrent, bir satır:** Kaydetme penceresinden eklenen torrent artık iki kez görünmüyor (biri iniyor, biri 0 B duraklatılmış). Dosya listesini göstermek için eklenen ön izleme kopyası ikinci kopya eklenmeden kullanılıyor.
- **Dosya seçimi çalışıyor:** Pencerede işaretini kaldırdığın dosyalar gerçekten atlanıyor. Önceden hepsi iniyordu.
- **Titreme yok:** Detay panelindeki Dosyalar ve Trackerlar sekmeleri her yenilemede yanıp sönmüyor, zıplamıyor.
- **Boyutlandırılabilir panel:** Alt panelin üst kenarından tutup sürükleyerek büyüt veya küçült. Kenara çift tıklayınca eski boyuna döner. Boyut hatırlanır.

## Eklenenler
- Detay panelinin üst kenarında sürükleme tutamacı: fare/kalemle sürükleme, klavyede Yukarı/Aşağı ok, çift tıkla sıfırlama; yükseklik pencereye göre sınırlı ve yeniden açılışta korunur (#65).

## Düzeltilenler
- Kaydetme penceresi → torrent: ön izleme kopyası ve seçilen dosyalar pencere ile indirme motoru arasında kayboluyordu (hem tarayıcı isteği hem link ekleme yolunda); aria2 torrenti ikinci kez alıyordu (#64).
- Güvenlik ağı: bu bağ olmadan eklenen torrentte, aynı info hash'e sahip duraklatılmış ön izleme kopyası ikinci kopya eklenmeden kullanılır; info hash artık çok dosyalı olanlar dahil `.torrent` dosyalarından da okunur (#64).
- Detay paneli sekmeleri her yenilemede yeni veri gelmeden boşaltılıyordu, bu da titremeye yol açıyordu; içerik artık tek adımda ve yalnız değiştiyse güncellenir, dosya listesi hatası her saniye değil bir kez gösterilir (#65).

## Bilinen Sorunlar
- Eski sürümden kalan çift satır **Kaldır** ile silinebilir; v2.7.1'de bu satır silinemiyordu (v2.7.2'den beri düzeltildi).
