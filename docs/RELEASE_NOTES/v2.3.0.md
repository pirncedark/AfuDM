# AfuDM v2.3.0 — Reliability & Security

AfuDM v2.3.0 closes the security debts that earlier releases deliberately deferred, and makes the interface fail loudly instead of hanging. Plugin packages are now verified before installation, archive extraction is bounded, and no bridge call can block the UI forever.

## Highlights

- Plugin packages are verified by SHA-256 before installation.
- Archive extraction is bounded in size and compression ratio (zip bomb protection).
- Plugin network access is restricted to the domains declared in its manifest.
- Manual "revert to previous version" for plugins, from the interface.
- No UI call can hang forever any more.
- Backup, restore, integrity check and diagnostics bundle.

## Added

- `sha256` manifest field, verified against the real package digest at install time. Mismatch rejects the install (`OZET_UYUSMUYOR`).
- "Allow unsigned plugins" setting (on by default). When off, a package without a digest is rejected; when on, the interface shows an unsigned warning.
- Archive limits as settings: total uncompressed size (200 MB) and compression ratio (100:1), both editable in the interface.
- Domain enforcement in the plugin host: a request to a domain outside the manifest list is blocked and logged.
- Manual plugin rollback with a confirmation step, plus its API endpoint.
- Backup, restore, integrity check, engine restart, health check and diagnostics export.
- Negative test cases for auth headers in `tests/maestro_test.mjs`.

## Changed

- Schema raised to `user_version = 10`: the `plugins` table gained a `sha256` column. Existing rows are untouched.
- GitHub Actions upgraded to Node 24 compatible majors.
- Error toasts now stay 9 seconds instead of 3.4, so a failure can actually be read.

## Fixed

- **Bridge calls could hang the interface forever.** Only `snapshot` had a timeout; every other call waited indefinitely, so an unresponsive engine silently froze the UI. All calls now have a timeout, with longer budgets for genuinely slow operations such as plugin installation and backup restore.
- The speed graph no longer spreads a 180-element array on every frame.

## Security

- Package integrity is verified before installation, not merely recorded.
- Extraction is bounded, so a malicious `.afup` can no longer exhaust disk space. Path traversal was already blocked.
- Declared plugin domains are now enforced at the host level rather than only displayed.
- This remains a **trusted plugin** model: the separate process gives fault isolation, not a security sandbox.

## Known Issues

- Responsive layout still has a single breakpoint; tablet and wide layouts are not tuned.
- ARIA coverage is thin; screen-reader support needs work.
- A few bridge-level error strings in `app.py` are not routed through i18n.
- No TLS on the headless panel; use it on a trusted network.

## Install

Download the Windows zip, extract it, and run `AfuDM.exe`.

## Türkçe

AfuDM v2.3.0, önceki sürümlerde bilerek ertelenen güvenlik borçlarını kapatır ve arayüzün takılmak yerine hata vermesini sağlar. Eklenti paketleri kurulumdan önce doğrulanır, arşiv açma sınırlandırılır ve hiçbir köprü çağrısı arayüzü süresiz bekletemez.

### Öne çıkanlar

- Eklenti paketleri kurulumdan önce SHA-256 ile doğrulanır.
- Arşiv açma boyut ve sıkıştırma oranıyla sınırlandırıldı (zip bomb koruması).
- Eklentinin ağ erişimi manifestte bildirdiği alan adlarıyla sınırlı.
- Arayüzden elle "önceki sürüme dön".
- Hiçbir arayüz çağrısı artık süresiz bekleyemez.
- Yedekleme, geri yükleme, bütünlük kontrolü ve tanı paketi.

### Eklendi

- Manifest'e `sha256` alanı; kurulumda paketin gerçek özetiyle karşılaştırılır. Uyuşmazsa kurulum reddedilir (`OZET_UYUSMUYOR`).
- "İmzasız eklentiye izin ver" ayarı (varsayılan açık). Kapalıyken özeti olmayan paket reddedilir; açıkken arayüz imzasız uyarısı gösterir.
- Arşiv sınırları ayar olarak: toplam açılmış boyut (200 MB) ve sıkıştırma oranı (100:1), ikisi de arayüzden düzenlenebilir.
- Eklenti host'unda alan adı zorlaması: manifest listesi dışındaki isteğe izin verilmez ve günlüğe yazılır.
- Onay adımlı elle eklenti geri alma ve API ucu.
- Yedekleme, geri yükleme, bütünlük kontrolü, motoru yeniden başlatma, sağlık kontrolü ve tanı dışa aktarımı.
- `tests/maestro_test.mjs` içine kimlik başlıkları için negatif vakalar.

### Değişti

- Şema `user_version = 10`: `plugins` tablosuna `sha256` sütunu eklendi. Mevcut satırlar ellenmez.
- GitHub Actions, Node 24 uyumlu majör sürümlere yükseltildi.
- Hata bildirimleri 3.4 saniye yerine 9 saniye kalıyor; hata artık okunabiliyor.

### Düzeltildi

- **Köprü çağrıları arayüzü süresiz kilitleyebiliyordu.** Yalnızca `snapshot` zaman aşımlıydı; diğer tüm çağrılar sonsuza kadar bekliyor, motor yanıt vermeyince arayüz sessizce donuyordu. Artık her çağrının zaman aşımı var; eklenti kurulumu ve yedek geri yükleme gibi gerçekten uzun işlere daha geniş süre tanınıyor.
- Hız grafiği artık her karede 180 elemanlı diziyi yaymıyor.

### Güvenlik

- Paket bütünlüğü yalnızca kaydedilmiyor, kurulumdan önce doğrulanıyor.
- Arşiv açma sınırlı; kötü niyetli bir `.afup` artık diski dolduramaz. Yol geçişi zaten engelliydi.
- Eklentinin bildirdiği alan adları artık yalnız gösterilmiyor, host düzeyinde uygulanıyor.
- Bu hâlâ **güvenilen eklenti** modelidir: ayrı süreç hata yalıtımı sağlar, güvenlik kum havuzu değildir.

### Bilinen sorunlar

- Responsive düzende hâlâ tek kırılma noktası var; tablet ve geniş ekran düzeni ayarlanmadı.
- ARIA kapsaması zayıf; ekran okuyucu desteği çalışma istiyor.
- `app.py` içinde birkaç köprü hata metni i18n'den geçmiyor.
- Arayüzsüz panelde TLS yok; güvendiğin ağda kullan.

### Kurulum

Windows zip dosyasını indir, arşivi çıkar ve `AfuDM.exe` dosyasını çalıştır.
