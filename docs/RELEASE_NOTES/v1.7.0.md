# AfuDM v1.7.0 — Torrent Pro

AfuDM now handles torrents as a first-class download type. You can inspect a torrent
before committing to it, pick exactly which files to download — including from a magnet
link, before the metadata has even arrived — and watch live swarm metrics while it runs.
This release also hardens the torrent UI against stale network responses, so a slow or
reopened panel can no longer overwrite what you are looking at.

## Highlights

- Pick individual files from a `.torrent` or magnet link before the download starts.
- Live swarm metrics: seeders, peers, share ratio, upload/download speed, tracker health.
- A detail drawer with Overview, Files, Trackers and Logs tabs for every download.
- Per-download logs: events are now tagged with their download id and can be filtered.

## Added

- Torrent file selection UI, including pre-selection for magnet links whose metadata
  has not resolved yet.
- Live torrent metrics panel (seeders, connected peers, ratio, up/down speed, live trackers).
- Tracker list and connected peer table.
- Behaviour tests for asynchronous races: `tests/torrent_yaris_test.mjs`.

## Changed

- The test runner now executes `.mjs` behaviour tests in addition to Python tests.
- Search inside the file list uses Turkish-aware case folding, so "İ/ı" and "I/i" match
  the way a Turkish user expects.

## Fixed

- Closing a torrent panel with `Escape` or a backdrop click now goes through the normal
  close path; the metrics polling timer is cleared instead of running forever.
- An open panel now refreshes its file list when magnet metadata arrives, so you no
  longer have to close and reopen it to choose files.
- The "first 250 files" display limit no longer counts folder rows, so deeply nested
  torrents always show actual files.
- Per-download log filtering now honours the requested download id instead of always
  returning the last 50 global events.
- Metric request failures are reported on the very first failure, with the server's
  error detail, instead of failing silently.
- Stale responses from a closed or reopened panel can no longer overwrite the current
  panel's files or metrics (window nonce + in-flight guards).
- The "no peers found" message is localised instead of being hard-coded Turkish.

## Security

- No injection, path traversal or XSS findings in this release's review.
- Database queries bind the download id and limit as SQLite parameters.

## Known Issues

- Some settings that exist in the backend still have no UI control (proxy, clipboard
  extensions, snail speed limit, API port). These are tracked in `docs/UI_EKSIKLER.md`
  and are scheduled for v1.7.5.
- `tests/i18n_test.py` has been observed failing once in a full-suite run and passing
  on every rerun with identical input; treated as flaky and under investigation.

## Install

Download the ZIP below, extract it anywhere (including a USB drive) and run `AfuDM.exe`.
No installation, no administrator rights, no registry changes required.
Verify the download against the SHA-256 table at the end of these notes.

## Türkçe

AfuDM artık torrentleri tam donanımlı bir indirme türü olarak ele alıyor. Bir torrenti
indirmeye başlamadan önce içini görebilir, hangi dosyaları indireceğinizi tek tek
seçebilir — magnet bağlantılarında metadata daha gelmeden bile — ve indirme sürerken
canlı sürü metriklerini izleyebilirsiniz. Bu sürüm ayrıca torrent arayüzünü gecikmiş ağ
yanıtlarına karşı sağlamlaştırıyor: yavaş kalan ya da yeniden açılan bir pencere artık
baktığınız veriyi ezemiyor.

### Öne çıkanlar

- `.torrent` veya magnet bağlantısında indirme başlamadan dosya seçimi.
- Canlı metrikler: seeder, peer, paylaşım oranı, yükleme/indirme hızı, tracker sağlığı.
- Her indirme için Genel Bakış, Dosyalar, Trackerlar ve Günlükler sekmeli detay çekmecesi.
- İndirmeye özel günlükler: olaylar artık indirme kimliğiyle etiketleniyor ve filtrelenebiliyor.

### Düzeltilenler

- `Escape` veya boşluğa tıklayarak kapatma artık normal kapanış yolundan geçiyor;
  metrik zamanlayıcısı sonsuza kadar çalışmak yerine temizleniyor.
- Magnet metadata'sı gelince açık pencere dosya listesini kendiliğinden yeniliyor.
- "İlk 250 dosya" sınırı artık klasör satırlarını saymıyor.
- İndirmeye özel günlük filtresi istenen kimliği dikkate alıyor.
- Metrik hatası ilk başarısızlıkta, sunucunun verdiği ayrıntıyla birlikte gösteriliyor.
- Kapanmış veya yeniden açılmış pencerenin gecikmiş yanıtı güncel veriyi ezemiyor.
- "Peer bulunamadı" metni artık sabit Türkçe değil, iki dilde.
- Aramada Türkçe I/i eşleşmesi doğru çalışıyor.

### Bilinen eksikler

- Arka planda çalışan bazı ayarların arayüzde karşılığı hâlâ yok (proxy, pano uzantıları,
  salyangoz hız limiti, API portu). `docs/UI_EKSIKLER.md` içinde izleniyor, v1.7.5'e alındı.
- `tests/i18n_test.py` tam süit koşumunda bir kez düşüp aynı girdiyle sonraki her koşumda
  geçti; kararsız (flaky) kabul edildi, araştırılıyor.
