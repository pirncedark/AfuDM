# AfuDM v3.4.8 — Download Visibility and Folder Controls

AfuDM now keeps active, queued, and waiting downloads visible when the download engine is temporarily unreachable. This release also improves per-download destination folders, remembers the last used folder, opens the actual download folder, and handles large torrent requests.

## Highlights
- Active downloads remain visible during temporary engine connection errors.
- Download destinations can be managed per download, and the last selected folder is remembered.
- Open-folder actions target the actual download location.
- Large torrent requests are handled reliably.

## Added
- Per-download destination folder controls and last-used-folder memory.

## Changed
- Folder actions now open the real location of the selected download.

## Fixed
- Active, queued, and waiting database records remain visible in the download list when an engine RPC snapshot fails.
- Large `.torrent` RPC submissions are supported.

## Security
- No security changes are included in this release.

## Known Issues
- No new known issues are recorded for this release.

## Install
- Use the in-app update when it becomes available, or download the Windows x64 package from the release assets.

## Türkçe

AfuDM, indirme motoruna geçici olarak erişemediğinde etkin, sıradaki ve bekleyen indirmeleri görünür tutar. Bu sürüm ayrıca indirme başına klasör seçimini geliştirir, son kullanılan klasörü hatırlar, doğru indirme klasörünü açar ve büyük torrent isteklerini işler.

## Öne Çıkanlar
- Motor bağlantısı geçici olarak kesilse de etkin indirmeler listede görünür.
- Her indirme için hedef klasör seçilebilir ve son seçilen klasör hatırlanır.
- Klasörü aç eylemi seçili indirmenin gerçek konumunu açar.
- Büyük torrent istekleri güvenilir biçimde işlenir.

## Eklenenler
- İndirme başına hedef klasör kontrolü ve son kullanılan klasörün hatırlanması.

## Değişiklikler
- Klasör eylemleri artık seçili indirmenin gerçek konumunu açar.

## Düzeltilenler
- Motor RPC anlık görüntüsü hata verdiğinde etkin, sıradaki ve bekleyen kayıtlar indirme listesinde kalır.
- Büyük `.torrent` RPC istekleri desteklenir.

## Güvenlik
- Bu sürümde güvenlik değişikliği bulunmuyor.

## Bilinen Sorunlar
- Bu sürüm için yeni bir bilinen sorun kaydedilmedi.
